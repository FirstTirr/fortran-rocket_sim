# fortran-rocket_sim

A rocket flight simulation project using Fortran for physics calculations and Python for visualization.

## Structure
- `src/`: Fortran source code
- `viz/`: Python visualization scripts
- `build.ps1`: PowerShell build script

## How to Run
1. Run `./build.ps1` to compile.
2. Run `./exe/rocket_sim.exe` to simulate.
3. Run `python viz/visualize_rocket.py` to see the results.
